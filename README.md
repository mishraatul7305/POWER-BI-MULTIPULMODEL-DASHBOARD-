# POWER-BI-MULTIPULMODEL-DASHBOARD- 
## Overview
This Power BI dashboard provides interactive insights into product performance, customer orders, quantity distribution, and payment modes. It enables users to explore business trends through dynamic charts, KPI cards, filters, and visual analytics.

## Features
- 📦 Product Analysis
- 📈 Order Analysis
- 💳 Payment Mode Distribution
- 📊 KPI Gauge
- 🎯 Interactive Filters
- 📉 Bar, Line & Donut Charts

## Tools Used
- Power BI
- DAX
- Power Query
- Data Visualization
